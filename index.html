HTML (HyperText Markup Language) is the standard markup language used to structure content on the web. It acts as the skeleton of a webpage, telling web browsers how to organize and display text, images, links, and multimedia

CSS BASICS

Introduction

CSS (Cascading Style Sheets) is the language used to style and lay out web pages by controlling colors, fonts, spacing, and positioning. While HTML builds the structure of a webpage, CSS handles its visual presentation
